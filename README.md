## ✨ About

**Step Into Wonder** is my personal developer portfolio — a place where **full-stack engineering, AI, and interactive 3D design** come together.

The landing experience opens with a scroll-driven parallax intro and a floating 3D companion, before moving into a clean, structured walkthrough of my work:

- Full-stack development projects
- AI-powered applications
- Technical skills & journey
- Resume and contact information

> *Build useful things, learn continuously, and make technology feel a little more alive.*

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nayan777pratyush/MyPortfolio.git
```

### 2. Navigate into the project

```bash
cd MyPortfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local Vite development URL shown in the terminal.
